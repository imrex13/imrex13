### TECTOVIA — Voice-Controlled Quiz Platform for Visually Impaired

<div align="left">

[![Patent](https://img.shields.io/badge/Patent-Filed-1e3a8a?style=flat-square&logo=googledocs&logoColor=white)](https://github.com/imrex13)
[![DST](https://img.shields.io/badge/DST-Funded-f97316?style=flat-square&logo=handshake&logoColor=white)](https://github.com/imrex13)
[![Users](https://img.shields.io/badge/Users-1300%2B-22c55e?style=flat-square&logo=users&logoColor=white)](https://github.com/imrex13)
[![Production](https://img.shields.io/badge/Status-Live-06b6d4?style=flat-square&logo=statuspage&logoColor=white)](https://github.com/imrex13)

</div>

<br/>

<table>
<tr>
<td width="50%" valign="top">

**The Problem**

Standard quiz platforms are completely unusable for visually impaired students, creating a significant barrier to accessible education.

**The Solution**

Voice-controlled quiz system with dual-layer speech architecture designed for production use at scale.

</td>
<td width="50%" valign="top">

**Performance Metrics**

- **97%** task success rate
- **2.9ms** average response time
- **<3ms** keyword detection latency
- **1300+** concurrent user in load testing

</td>
</tr>
</table>

**Technical Architecture:**

```
┌─────────────────────────────────────────────────────────┐
│  LAYER 1: Vosk Keyword Spotting (Offline)              │
│  • Real-time navigation commands                        │
│  • Sub-3ms latency                                      │
│  • No network dependency                                │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  LAYER 2: Whisper STT (Natural Language)               │
│  • Answer input processing                              │
│  • Intent parsing                                       │
│  • Graceful online/offline state handling              │
└─────────────────────────────────────────────────────────┘
```

**Tech Stack:** `Node.js` `Express` `MongoDB` `Python` `Vosk` `Whisper` `Kokoro TTS` `WebSockets`

> **Note:** Code is proprietary (DST funded, patent pending). Architecture documentation available on request.

<div align="left">

Multi-camera real-time fire and smoke detection system designed for existing camera infrastructure — **no hardware replacement needed**.

**Key Features:**
- Backend architecture and API layer built from scratch
- Live deployment on AWS EC2 with NGINX reverse proxy
- Concurrent camera stream ingestion and intelligent alert routing
- Production-grade monitoring and failover handling

**Tech Stack:** `Node.js` `Express` `MongoDB` `AWS EC2` `NGINX`

### Offline AI Assistant

<div align="left">

[![Repo](https://img.shields.io/badge/Code-Open%20Source-22c55e?style=flat-square&logo=github&logoColor=white)](https://github.com/imrex13)
[![Type](https://img.shields.io/badge/Type-Final%20Year%20Project-blue?style=flat-square&logo=graduation-cap&logoColor=white)](https://github.com/imrex13)

</div>

<br/>

Complete RAG pipeline running entirely offline — **zero cloud dependency, no data leaving device**. Built as final year project with focus on privacy-first architecture.

**Features:**
- ChromaDB vector store with per-chat collection isolation
- Dual LLM architecture using Ollama + LLaMA 3.2:1B
- File upload, vector indexing, and session memory management
- Fully local inference — complete data privacy

**Tech Stack:** `Python` `ChromaDB` `Ollama` `LLaMA 3.2`
